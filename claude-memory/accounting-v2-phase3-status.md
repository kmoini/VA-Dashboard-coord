**What exists (all behind the flag, per firm):** `LedgerEntryDTO` +eventAware/eventCode/eventModifiers/chosenAccountId/fundingAccountName/counterAccountName, `settlesTransactionId()`, `isTransfer()`, `holdReason()`; hash adds a `v2` block ONLY when on (⚠️ never add unconditionally: every pushed row would go stale). `QuickBooksEntityMapper`: ENTITY_TRANSFER/BILL_PAYMENT/PAYMENT/INVOICE, `entityTypeFor` event-first, whole-entity builders `transferPayload/billPaymentPayload/paymentPayload`, lines use `resolver->accountForEntry(gifi, type, chosenId)`, funding via `fundingAccountFor(key, method, registryName, strict)`. `QuickBooksReferenceResolver`: `accountForEntry` (human GIFI mapping → chosen → legacy), `pushedEntityIdFor(conn, txId, 'Bill'|'Invoice')` reads transaction_integration_syncs, `fundingAccountFor` strict mode (registry name match or the ONLY account of the kind, else null), locale fix in `deriveAccountFromGifi` (flag-independent). `QuickBooksExportProvider::push` returns `skipped` on `holdReason()`. `BusinessEventResolver` drops EVENT_UNSUPPORTED for the 5 covered events when the firm's flag is on (`EventContext::firmId` added). Tests: `tests/Feature/AccountingV2/EventPostingTest.php` (11, own Http fake with TWO bank accounts). Legacy Integrations + QuickBooks suites unchanged (441 green, flags off).

**Gotchas:** QBO entity URLs: "/billpayment" contains "/bill", so any Http fake must match longer names first. BillPayment payload: `PayType` Check|CreditCard + `CheckPayment.BankAccountRef` / `CreditCardPayment.CCAccountRef` + `Line[].LinkedTxn[{TxnId, TxnType:'Bill'}]`; Payment: `CustomerRef, TotalAmt, DepositToAccountRef, Line[].LinkedTxn[{TxnType:'Invoice'}]`; Transfer: `Amount, FromAccountRef, ToAccountRef`. Invoice reuses the SalesReceipt line shape (SalesItemLineDetail + AccountRef). Payment-account mappings are keyed by the REGISTRY ACCOUNT NAME (`ClientBankAccount.name`), so `fundingAccountName` is the lookup key. The router only accepts `forClient` connections while AccountCandidateResolver also takes firm-level ones (not changed).
